═══════════════════════════ KEY DESIGN FACTS ══════════════════════════════════

  • Stateless protocol  — every request is self-contained (_meta carries
                          version + capabilities + identity)
  • Transport-agnostic  — same JSON-RPC 2.0 wire format for all transports
  • Composable          — one host can connect to N servers simultaneously
  • Dynamic             — primitive lists can change; servers push notifications
  • Extensible          — optional extensions (e.g., Tasks) built on core
